# ChargeForecast

Android-приложение для отслеживания зарядки телефона: прогноз времени до 100%, сравнение скорости разных зарядок и кабелей, история сессий.

## Зачем это нужно

У автора несколько зарядок и несколько разных кабелей к ним. На практике они заряжают телефон с **разной скоростью** — но без измерений это не очевидно. Приложение должно:

- при подключении зарядки показывать, **сколько времени осталось до 100%**;
- показывать **текущую скорость зарядки** (%/мин, Вт при наличии данных по току/напряжению);
- вести **историю сессий** и привязывать их к профилям «зарядка + кабель», чтобы сравнивать связки между собой;
- подавать информацию удобно: **виджет** на домашнем экране, **постоянное уведомление** в шторке с прогрессом, и/или **экран при подключении**.

## Статус

Минимальная инициализация проекта. Собирается, запускается, показывает экран-заглушку с темой «Volt» (тёмный фон + акцент Electric Volt `#D1FF00`). Дальнейший функционал наращивается поэтапно:

1. Чтение состояния батареи (`BatteryManager`, `ACTION_BATTERY_CHANGED`).
2. Расчёт скорости зарядки и прогноза до 100%.
3. Постоянное уведомление в шоротке (`ForegroundService` + `NotificationManager`).
4. Виджет домашнего экрана.
5. История сессий и профили зарядок в DataStore.
6. Экраны: текущая сессия, история, профили, настройки.

## Стек

- Kotlin + Jetpack Compose + Material 3
- DataStore Preferences (история/настройки)
- Один модуль `:app`, ручная навигация
- minSdk 29, targetSdk 36, compileSdk 36

## Сборка

```powershell
.\gradlew.bat assembleDebug
```

Установка на подключённое устройство:

```powershell
.\gradlew.bat installDebug
```

> Версия (`version.properties`) автоматически увеличивает patch при `assemble`/`install`/`bundle`.

## Структура

```
app/
  src/main/
    java/com/example/chargeforecast/
      MainActivity.kt          # точка входа + экран-заглушка
      AppVersion.kt            # версия из BuildConfig
      ui/theme/                # палитра Volt, типографика, тема
    res/
      values/                  # strings, themes, colors
      xml/                     # правила backup
      drawable/                # векторная иконка-молния (launcher)
      mipmap-anydpi-v26/       # adaptive-icon
  build.gradle.kts
gradle/libs.versions.toml      # каталог версий зависимостей
version.properties             # версия приложения
AGENTS.md                      # правила для AI-агентов
```
