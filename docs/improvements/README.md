# ChargeForecast — план улучшений

Документы для реализации в отдельных сессиях. Каждый файл самодостаточен:
диагноз с доказательствами, варианты решения, пошаговый план, критерии приёмки.
Код в этой папке не меняется — только планы.

Составлено по итогам анализа ревизии `1ddbdb9` (mvp version) и живой сессии
автора (шторка не стартует от кабеля, прыжки прогноза «25 мин → 1 ч 25 мин»,
строка «прошлая зарядка» равна текущей).

## Связь с открытым change `live-charge-forecast`

В change `live-charge-forecast` остались две задачи на устройстве автора
(калибровка 2.3 и контрольная сессия 5.2); остальные задачи change'а —
исторические. Документ 01 отменён (см. таблицу выше).

## Рекомендуемый порядок работ

```
01 (автостарт шторки)  ---- можно параллельно, независимый код
02 (конвейер измерений) ---- фазы 0..3, каждая фаза самостоятельно
                               поставляема и тестируема
```

Фаза 0 документа 02 — «быстрые победы» (~30–60 мин): убирает самые
заметные дефекты (равенство «прошлой» и текущей скорости, скачок ×2 на 80%)
без переписывания конвейера. Рекомендуется сделать первой.

## Правила для сессий-исполнителей

1. Перед началом прочитать соответствующий документ целиком.
2. Ссылки вида `Файл.kt:NN` актуальны для ревизии `1ddbdb9`; при расхождении
   искать по имени символа, не по строке.
3. После завершения проблемы: обновить таблицу «Статус» здесь и пройти
   чек-лист приёмки из документа.
4. Новый UI — только через токены темы Volt (см. AGENTS.md).
5. Тексты пользователю и комментарии — на русском, идентификаторы — на английском.
