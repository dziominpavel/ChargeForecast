# Proposal: estimate-from-first-second

## Why

Экран и виджет показывают тексты-заглушки («Собираю данные о расходе», «Измеряю… N с», «Средний расход пока не измерен») там, где можно показать честное приблизительное число. Автор требует: время спервой секунды, без заглушек — при отсутствии данных опираемся на приоры (разряд: 100% = 24 ч; зарядка: тип подключения), дальше плавно переезжаем на факт. Параллельно: служебное уведомление «Слежение за зарядкой активно» видно в шторке и не несёт пользы, а секунды в остатке дёргают число и нужны только в последнюю минуту.

## What Changes

- **Приор разряда «100% = 24 ч».** Пока окно наблюдений неполное (меньше 2 часов за скользящие сутки), оценка оставшейся работы считается из приора: весь заряд ≈ 24 часа работы. Вес приора плавно гаснет (smoothstep) по мере накопления наблюдений и обращается в нулю к 2 часам окна — переход без скачка. Прибор без счётчика заряда (окно не заполняется вовсе) получает осознанный деград: всегда приор, но число есть. Состояние «сбора данных» в разряде исчезает.
- **Приор зарядки по типу подключения** (AC ≈ 2 ч, USB ≈ 6 ч, беспроводная ≈ 4 ч, неизвестно ≈ 3 ч — «от 0 до 100%»): подмешивается в существующий слот истории (`HistoryBlender`), поэтому отсчёт до 100% показывается с первой секунды даже при чистой установке, а плавный уход к живым замерам идёт по существующему расписанию 10 с → 180 с.
- **Удаление текстов-заглушек**: «Собираю данные о расходе» (+ подсказка про два часа), «Средний расход пока не измерен», «Собрано X из 24-часового окна», «Собираю данные…» (экран и виджет), «Измеряю… N с», «Измеряю…» (виджет), «Собираю…», «Жду данные». Строки, которым не остаётся случая, удаляются из `strings.xml`; UI не показывает строку вместо заглушки. Метки точности «примерно / точно / уточняю» и предупреждение «Слежение остановлено — откройте приложение» остаются.
- **Формат остатка без секунд**: секунды — только когда осталось меньше минуты; меньше часа — «N мин»; час и больше — «H ч M мин». Действует на экране и на виджете (общая функция форматирования).
- **Виджет без секундного тика**: постоянный Chronometer/H:MM:SS отменён; в последнюю минуту зарядки (остаток < 60 с) виджет показывает секунды и обновляется чаще (толчок раз в секунду вместо троттлинга 15 с), до этого — минутный формат с обычным троттлингом.
- **Служебное уведомление без текста**: в шторке остаётся только иконка и имя приложения — без «Слежение за зарядкой активно». Скрытие канала (`IMPORTANCE_NONE`) сохраняется как задумка; статичность сохраняется.
- Change `smooth-anchored-countdown` закрыт как утративший актуальность: его посылка (секунды всегда, Chronometer на виджете) отменена этим change'ом; якорное сглаживание показа можно вернуть отдельно, если минутные цифры на границах будут мигать.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `discharge-estimate`: требование «Оценка по среднему расходу» — вместо состояния сбора данных приор «100% = 24 ч» с плавным переходом на измеренное среднее; требование «Оценка объяснима» — показывается средний ток только когда измерен, строка окна наблюдения и pending-строки исчезают.
- `charge-forecast`: приор скорости по типу подключения при чистой установке (цифры с первой секунды без «Измеряю…»); требование «Фильтр показа» и «Честная индикация точности» — формат остатка с секундами только в последнюю минуту; ярус «Измеряю…/собираю данные» исчезает.
- `battery-widget`: «Виджет честно деградирует» — состояния «сбора данных»/«нет данных» без текстов-заглушек; формат времени виджета без секунд кроме последней минуты; обновление в последнюю минуту не реже раза в секунду.
- `background-tracking`: «Служебное уведомление не является поверхностью продукта» — содержимое уведомления без текста (только иконка и имя приложения).

## Impact

- **Код разряда**: `forecast/DischargeEstimator.kt` (приор + плавный смесь вместо `collecting`), `session/SessionEngine.kt` (передача уровня в оценку), `ui/SessionScreen.kt` (карточка разряда без заглушек и строки окна), `widget/WidgetText.kt` (режим COLLECTING исчезает).
- **Код зарядки**: `session/SessionEngine.kt` (приор в слот истории), `forecast/ChargeForecaster.kt` (ярус COLLECTING не достижим при подключённом кабеле), `ui/ForecastText.kt` (формат остатка), `ui/SessionScreen.kt`.
- **Виджет**: `widget/BatteryWidgetProvider.kt`, `widget/BatteryWidgetUpdater.kt` (троттлинг зависит от остатка), `widget/WidgetText.kt`.
- **Сервис**: `service/ChargeForecastService.kt` (уведомление без текста), `res/values/strings.xml` (удаление строк).
- **Тесты**: `DischargeEstimatorTest`, `SessionEngineTest`, `WidgetTextTest`, `SessionCacheTest` (без изменений — персист не трогается), `BatterySnapshotTest` (без изменений).
