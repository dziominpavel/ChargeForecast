# ChargeForecast

Android-приложение для отслеживания зарядки телефона: прогноз времени до 100% в часах/минутах/секундах (новое значение каждую секунду), текущая скорость зарядки, экран текущей сессии.

Слежение **фоновое**: телефон сам замечает вставку кабеля, приложение открывать не нужно. Прогноз виден на виджете домашнего экрана — на зарядке остаток до 100%, в простое приблизительное оставшееся время работы.

## Зачем это нужно

У автора несколько зарядок и несколько разных кабелей к ним. На практике они заряжают телефон с **разной скоростью** — но без измерений это не очевидно. Приложение показывает при подключении зарядки:

- **сколько времени осталось до 100%** (ч/мин/с, обновление каждую секунду);
- **текущую скорость зарядки** (%/мин, ток/вольтаж при наличии данных);
- статус точности («примерно» / «уточняю» / «точно»).

Форма подачи — живой экран сессии и виджет домашнего экрана (шторка-уведомление удалена из продукта решением автора). В будущем: история сессий и профили «зарядка + кабель» для сравнения связок.

## Статус

Рабочее приложение: живой конвейер «батарея → скорость → прогноз → экран и виджет» (опрос 1 Гц на зарядке, три спидометра + fusion, кривая доводки по корзинам, замороженная сводка прошлой сессии как приор). Фоновое слежение поднято: постоянный foreground service ловит вставку кабеля без открытого приложения, опрос в простое остановлен и пробуждается по событию. Дальше:

1. ~~Постоянное уведомление в шторке~~ — удалено решением автора.
2. ~~Виджет домашнего экрана~~ — отсчёт до 100% и оценка работы, режим выбирается сам.
3. Калибровка констант spike-замером на устройстве автора.
4. Контрольная живая сессия 20+ мин и проверка, что EMUI не убивает сервис.
5. История сессий и профили зарядок, экраны истории/профилей/настроек.

## Стек

- Kotlin + Jetpack Compose + Material 3
- SharedPreferences (`SessionCache`: ёмкость, сводка прошлой сессии, кривая доводки по типу подключения, история последних зарядок, накопитель расхода)
- Один модуль `:app`, ручная навигация
- Фоновое слежение — foreground service (`specialUse`) без сторонних библиотек; виджет — `RemoteViews`/`AppWidgetProvider`
- minSdk 29, targetSdk 36, compileSdk 36

## Сборка

```powershell
.\gradlew.bat assembleDebug
```

Установка на подключённое устройство:

```powershell
.\gradlew.bat installDebug
```

> Версия — файл `version`: меняется только release-скриптом, при `assemble`/`install`/`bundle` не увеличивается.

## Структура

```
app/
  src/main/
    java/com/example/chargeforecast/
      MainActivity.kt          # точка входа → ChargeForecastApp()
      ChargeForecastApplication.kt  # ручной DI: мониторы на процесс
      battery/                 # BatteryMonitor, BatterySnapshot, SysfsCurrent/Capacity
      forecast/                # спидометры, fusion, прогноз, кривая доводки, фильтр, оценка разряда
      session/                 # SessionEngine, монитор StateFlow, кэш SharedPreferences
      service/                 # ChargeForecastService (foreground), BootCompletedReceiver
      widget/                  # виджет: модель режима, AppWidgetProvider, троттлинг обновлений
      ui/                      # экран сессии, форматирование, тема
    res/
      values/                  # strings, themes, colors, dimens
      layout/                  # виджет: widget_battery.xml
      xml/                     # правила backup, battery_widget_info.xml
      mipmap-anydpi-v26/       # adaptive-icon
  build.gradle.kts
gradle/libs.versions.toml      # каталог версий зависимостей
version                        # версия приложения (только release-скрипт)
AGENTS.md                      # правила для AI-агентов
```
