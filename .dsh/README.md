# `.dsh/` — окружение DeepSeek Harness для этого проекта

Навыков в проекте нет: рабочий набор (OpenSpec и остальное) живёт в профиле DSH —
это плагин `dsh-skillpack` в `C:\projects\DeepseekPlugins\plugins\dsh-skillpack`.
Правишь один раз там — видно во всех проектах, отдельных копий не нужно.

Проектный навык нужен, только если он специфичен для этого репозитория:
`.dsh/skills/<name>/SKILL.md`. Он главнее набора.

Правила проекта — в `AGENTS.md`, их DSH загружает сам.

Копии OpenSpec-навыков здесь больше не держим: `openspec update` считает проект
настроенным на DSH только пока существует `.dsh/skills`, поэтому после удаления
каталога он их не вернёт. Для cursor/devin/opencode генерация не менялась.
